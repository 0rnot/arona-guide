プライバシーポリシー

2026年10月14日 制定

Discord ボット「AronaBot」（以下「アロナ」）と、そのサイト arona-bot.com が、どんな情報を扱い、何に使い、いつ消すかをまとめたものです。アロナは個人が趣味で運営している非公式のファン制作物です。

アロナが受け取る情報

アロナはふつうの会話のメッセージを読みません。受け取るのは、あなたがスラッシュコマンド・ボタン・メニューを使ったときに Discord から届く情報だけです。

  • Discord のユーザー ID・サーバー ID・チャンネル ID と、サーバー名
  • 使ったコマンドの名前と、コマンドに入力した内容
  • メッセージを右クリックして「リマインダー設定」を選んだときは、そのメッセージの ID

保存する情報と使い道

  • ガチャ（/g）の記録 — サーバーごと・ユーザー ID ごとに、引いた回数・★の内訳・お迎えした生徒の名前・最初と最後に引いた日時。「記録」と「番付」の表示に使います。番付は同じサーバーの人に見えます
  • リマインダー — 予約した人のユーザー ID、チャンネル ID、対象のメッセージ ID、通知する時刻。時刻が来たら通知し、記録を消します
  • サーバーの設定（/settings） — 通知の ON/OFF と投稿先のチャンネル ID
  • 利用の記録 — 「いつ・どのユーザー ID が・どのサーバーで・どのコマンドを使ったか」をサーバーのログに残します。不具合の調査と、利用状況の集計に使います
  • 招待リンクのクリック — arona-bot.com などの「サーバーに招待する」を押すと、api.arona-bot.com を経由して Discord の招待画面へ移ります。このとき、どの入口のリンクか・日時・ブラウザの種類を記録します。IP アドレスはそのまま残さず、元に戻せない形（ハッシュ）に変えてから記録します
  • Tier 表の共有（/tier と Tier 表メーカー） — 共有した Tier 表の中身。最後に保存してから 14 日で消えます

外部のサービスに送る情報

  • リマインダーの時刻を自由入力で指定したときだけ、その入力文（時刻の書き方）を時刻を読み取るために Google の Gemini API へ送ります。メッセージの本文は送りません
  • これ以外に、あなたの情報を第三者に売ったり渡したりすることはありません

保存期間

  • ガチャの記録とサーバーの設定は、消す依頼があるまで、またはアロナがサーバーから外されるまで残ります。サーバーから外されたときは、そのサーバーの設定を消します
  • リマインダーは通知した時点で消えます
  • 利用の記録と招待リンクのクリックは、ログの容量の上限に達した古いものから順に消えます

消してほしいとき・問い合わせ

自分の記録を消してほしいとき、この方針について聞きたいことがあるときは、Discord の @0r.not か、X の @PE6K4C まで連絡してください。ユーザー ID がわかれば、そのユーザーのぶんをまとめて消します。

このページの変更

アロナの機能が変わって扱う情報が増えたときは、このページを書き直し、日付を更新します。
