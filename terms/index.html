利用規約

2026年10月14日 制定

Discord ボット「AronaBot」（以下「アロナ」）と、そのサイト arona-bot.com を使う前に読んでください。アロナをサーバーに招待した時点、またはコマンドを使った時点で、この規約に同意したものとします。

アロナについて

  • アロナは個人が趣味で運営している、ブルーアーカイブの非公式のファン制作物です。Nexon Games・Yostar とは関係ありません
  • ゲーム内の画像・名称・数値の著作権は、すべて権利者に帰属します
  • 利用は無料です

ガチャ（/g）について

  • /g はゲームの募集をまねただけのシミュレーターです。お金・ゲーム内の通貨・アイテムを賭けたり、受け取ったりすることはできません
  • 結果はゲーム本編のアカウントにも、実際の募集の確率にも影響しません

してはいけないこと

  • アロナや arona-bot.com に、わざと大量の要求を送って負荷をかけること
  • 不具合を悪用して、ほかの人の記録や設定を書き換えたり見たりすること
  • Discord の利用規約・コミュニティガイドラインに反する使い方

こうした使い方を見つけたときは、予告なく、そのユーザーやサーバーでアロナを使えないようにすることがあります。

保証しないこと

  • 通知・ボーダー・開催予定などの情報は、公式の告知などから自動で読み取っています。正確さや、届く時刻は保証しません。大事な予定は公式の発表で確かめてください
  • アロナは予告なく止まったり、機能が変わったり、終了したりすることがあります
  • アロナを使ったことで起きた損害について、運営者は責任を負いません

情報の扱い

アロナが扱う情報についてはプライバシーポリシーに書いています。

規約の変更と問い合わせ

この規約は、必要に応じて書き直し、日付を更新します。問い合わせは Discord の @0r.not か、X の @PE6K4C までどうぞ。
