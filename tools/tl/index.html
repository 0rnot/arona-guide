AronaBotの使い方/ツール/TL エディタ

ボスの EX（通常スキルの回数で撃つ） ボスの EX（2 種類目） ボスの EX（ゲージで撃つ） フェーズの切り替わる HP

編成

まだ形だけです。並べた生徒はレーンに行が増えるところまで動きます。

いまできること

  • ボスの動きが敷けます。いつどの EX を撃つか、フェーズがどの HP で切り替わるかを、ゲームのデータから出しています
  • 再生ヘッドが動きます。盤の上でカーソルを動かすと、残り時間が出ます
  • まだ無いもの。コストの線、手札、スキルの置きかけ、ダメージ。順に足していきます
数字の出どころ
  • ボスがいつ EX を撃つか — ba-data の DB/BossExternalBTExcelTable.json（ビヘイビアツリー）。 UseNormalSkill N → UseSelectExSkill i は「通常スキル N 発目のあとに EX の i 番」、 CheckPeriod ms → AddActiveGauge v と CheckActiveGaugeOver t はゲージで撃つぶん、 HPUnder hp → ChangePhase p はフェーズの切り替わりです
  • 通常スキル 1 発の長さ — LevelSkill/<スキル名>.json。 通常攻撃の型は AnimationFrames の AttackIngDuration、 Timeline の型はトップレベルの Duration。どちらもフレーム数で、30fps で秒に直しています
  • EX の並び — DB/CharacterSkillListExcelTable.json の ExSkillGroupId。 UseSelectExSkill の番号はこの並びを指します
  • ボスの HP と通常攻撃の速さ — DB/CharacterStatExcelTable.json の MaxHP1 と NormalAttackSpeed
  • スキルの名前と説明 — SchaleDB の raids
  • ここだけ当てにしないでください。難易度ぶんのビヘイビアツリーが無いボスは、 Normal の木で埋めています（スキル名と HP はその難易度のものを使っています）。 グレゴリオの Lunatic だけは木が無いので出せません
