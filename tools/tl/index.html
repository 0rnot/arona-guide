数字の出どころ
  • ボスがいつ EX を撃つか — ba-data の DB/BossExternalBTExcelTable.json（ビヘイビアツリー）。 UseNormalSkill N → UseSelectExSkill i は「通常スキル N 発目のあとに EX の i 番」、 CheckPeriod ms → AddActiveGauge v と CheckActiveGaugeOver t はゲージで撃つぶん、 HPUnder hp → ChangePhase p はフェーズの切り替わりです
  • 通常スキル 1 発の長さ — LevelSkill/<スキル名>.json。 通常攻撃の型は AnimationFrames の AttackIngDuration、 Timeline の型はトップレベルの Duration。30fps で秒に直しています
  • EX の並び — DB/CharacterSkillListExcelTable.json の ExSkillGroupId
  • ボスの HP と通常攻撃の速さ — DB/CharacterStatExcelTable.json の MaxHP1 と NormalAttackSpeed
  • コスト回復力 — 1 人あたり 700（RegenCost）。6 人で 4200。 コストは 1 秒あたり 回復力÷10000 で増えます。開始から PlayerRegenCostDelay の 2 秒は増えません
  • スキルの名前と説明 — SchaleDB
  • ダメージの式 — SchaleDB の js/common.js（CharacterStats.calculateDamage ／ getDefenseDamageReductionMod ／ getCriticalRate ／ getHitChance ／ getStabilityMinDamageMod ／ getEffectiveMod ／ interpolateStat）を写しています。 式は自前で作っていません。日本語の解説は けーさんの本です
  • 特効（弾種 × 装甲） — DB/BulletArmorDamageFactorExcelTable.json。 貫通 → 重装甲が 20000（＝200%）、貫通 → 軽装甲が 5000（＝50%）
  • 地形 — DB/TerrainAdaptationFactorExcelTable.json の AttackPowerFactor。D 8000 ／ C 9000 ／ B 10000 ／ A 11000 ／ S 12000 ／ SS 13000。 市街・屋外・屋内で値は同じでした。ステージの地形は DB/GroundExcelTable.json の StageTopography
  • 敵のレベル — DB/RaidStageExcelTable.json の GroundId → DB/GroundExcelTable.json の LevelBoss（ビナー Torment は 90）
  • 支援値 — DB/CharacterStatsTransExcelTable.json。 SPECIAL の最終値の HP・攻撃 10%、防御・治癒 5% を切り捨てて STRIKER に足します
  • 育成の中身 — 装備は equipment.min.json の各段の上限レベルの値、 固有武器・愛用品・絆は students.min.json。星の伸びは SchaleDB の既定値 （生徒ごとの Transcendence は日本版のデータに 1 件もありませんでした）
  • 常時のパッシブ — パッシブと固有武器パッシブ（固有武器★2 以上）を乗せています。 同じ（スキルの枠, Channel）が 2 回来たら先に来たほうが勝つ、という SchaleDB の扱い（common.js 7723 行）に合わせました。 Condition や Restrictions が付く 30 件は 条件を確かめる術がないので乗せていません。 弱点を突いたときだけ乗る「◯◯特効増加」も入れています
  • 確かめ方 — SchaleDB の common.js から CharacterStats ／ MathHelper ／ getBondStats を 切り出して Node で走らせ、151 人ぶんを突き合わせました。 最終攻撃力は 151/151、ダメージは 150/151 が一致します。残る 1 件（チアキ）は CriticalCheck: "Never" のスキルで、参照側は会心倍率を必ず掛けますが こちらは掛けません。SchaleDB 自身のスキル表示も Never は会心率 0 にしています
  • 時限のバフ・デバフ — 置いた EX が掛けるバフは ApplyFrame ぶん遅れて始まり、Duration（ミリ秒）続きます。 対象は Self ／ AllyMain（STRIKER）／ AllySupport（SPECIAL）／ Enemy。 同じ（スキルの枠, Channel）が重なったら、後から掛けたほうが勝ちます （原則後掛け優先。常時のパッシブだけは SchaleDB に合わせて先勝ちです）。 敵に乗ったぶんは「デバフ数」のレーンに本数で出しています
  • 通常スキル（NS）の周期 — LevelSkill/<PublicSkillGroupId>.json の AutoUseRule。ConditionType: "Interval" なら ConditionArgument がフレームで、750 なら 25 秒ごとです。 272 人がこの型で、残る 68 件は OnAttackIng・HpUnder など 間隔で決まらない型なので置いていません（その生徒がいると左の欄に出ます）。 愛用品 T2 で通常スキルが変わる子は、そちらを使います
  • まだ入っていないもの — SS のダメージ、遮蔽、 キサキ枠（EX スキルダメージ量増加）、条件つきのバフ 30 件。 実戦の数字より小さく出ます
  • 当てにしないでください — 難易度ぶんのビヘイビアツリーが無いボスは Normal の木で埋めています。 グレゴリオの Lunatic だけは木が無いので出せません
