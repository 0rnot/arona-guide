数字の出どころ

レベルの表はゲームのクライアントから取り出したデータをそのまま使っています。推測した値はありません。

  • DB/AccountLevelExcelTable.json — レベルごとの必要経験値（Exp）と AP 上限（APAutoChargeMax）、新米先生経験値ブーストの倍率（NewbieExpRatio）、月額商品ぶんの PlusExpRatio1 / PlusExpRatio2
  • Excel/ConstCommonExcelTable.json — AccountMaxLevel: 90、AccountExpRatio: 1、熟達証書の週上限 MaxApMasterCoinPerWeek: 12000 と、月額パスで増えるぶん PlusMaxApMasterCoinPerWeek1: 2000 / PlusMaxApMasterCoinPerWeek2: 1000 （PlusMaxApMasterCoinPerWeekProductMonthlyId1/2 にそれぞれの商品 ID が入っています）
  • DB/ClanRewardExcelTable.json — サークルの出席報酬が 10（ClanRewardType: Attendance）

AccountExpRatio が 1 なので、消費した AP と得られる先生経験値は 1 対 1 です。このツールが「必要経験値＝必要 AP」として扱っているのはそのためです。取得元は electricgoat/ba-data の jp ブランチで、Lv1 から Lv90 までの合計は 294,782 でした。取得は —。

1 日の AP の内訳は、レベルアップの回復を除いてすべてゲームのデータにあります（2026 年 8 月 31 日に突き合わせました）。

  • 自然回復 — DB/CurrencyExcelTable.json の ID 5（CurrencyType: "ActionPoint"）に AutoChargeMsc: 360000 / AutoChargeAmount: 1。6 分に 1 で、1 日 240 は 86,400 秒 ÷ 360 秒の計算です
  • デイリーミッション — DB/MissionExcelTable.json の Id 1513（Reset_DailyLogin、報酬が Currency 5 ＝ AP × 100）と Id 1508（Reset_CompleteScheduleCount: 2、報酬が AP × 50）。合計 150
  • サークル — DB/ClanRewardExcelTable.json（上の箇条書きのとおり 10。表にはこの 1 行しかありません）
  • 青輝石 — DB/ShopExcelTable.json の Id 21（CategoryType: "Ap"、PurchaseCountLimit: 20、PurchaseCountResetType: "Day"）が DB/GoodsExcelTable.json の商品 20 個を指していて、どれも AP 120 を渡します。値段（Currency 4 ＝青輝石）は 30 が 3 個・60 が 3 個・100 が 3 個・150 が 3 個・200 が 3 個・300 が 5 個——「1〜3 回目 30、4〜6 回目 60、7〜9 回目 100、10〜12 回目 150、13〜15 回目 200、16〜20 回目 300」と一致します
  • カフェ — DB/CafeProductionExcelTable.json の 1 号店（CafeId: 1）・AP（CafeProductionParcelId: 5）の ParcelStorageMax がランク 1〜10 で 90 / 150 / 220 / 300 / 390 / 460 / 530 / 600 / 670 / 740

レベルアップの回復だけはデータに見つかりません。神ゲー攻略「先生レベルの効率的な上げ方」に「即座にAPが最大値分回復する」とあります（ゲーム乱舞にも「レベルアップじのAP回復でAPがあふれてしまうことが多い」と、回復があること自体の記載があります）。「上限まで回復」か「上限ぶん足される」かはこの書き方では決められませんが、このツールは AP を使い切ってから上がる前提で各レベルの上限を足しているので、どちらの読み方でも同じ数になります。

「新米先生経験値ブースト」の倍率はゲームのデータに入っていました。DB/AccountLevelExcelTable.json の NewbieExpRatio がそれで、レベルごとに値が入っています（10000 分率。25000 なら ＋250%）。段はこうです。

  • Lv1〜50 — 25000（＋250%）
  • Lv51〜70 — 20000（＋200%）
  • Lv71〜83 — 15000（＋150%）
  • Lv84〜85 — 10000（＋100%）
  • Lv86〜88 — 5000（＋50%）
  • Lv89〜90 — 0（付きません）

同じ行の CloseInterval が段の終わりのレベル（50 / 70 / 83 / 85 / 88 / 90）と一致するので、この読み方で合っています。この列は Excel/ 側には無く、DB/ 側にしかありません。以前このツールが「データに入っていない」と書いて 50,000 という固定値を引いていたのは、Excel/ しか見ていなかったためです（2026-08-30 に直しました）。

ブーストは「必要な経験値が減る」のではなく「もらえる経験値が増える」ものです。神ゲー攻略「先生レベルの効率的な上げ方」に「取得経験値にボーナスが加わる」「新米先生経験値ブーストは、経験値2倍キャンペーンと同時に効果を受けられる」とあります。なので、このツールはレベルごとに必要経験値を倍率で割って足しています。まとめて掃討したときもレベルごとに計算し直されるという記載があるので、その読み方に合わせています。ただし同記事の倍率表（1〜20 が ＋200%、21〜40 が ＋150%、41〜60 が ＋100%、61〜70 が ＋50%）は、今のゲームのデータと合いません。レベル上限が 70 だった頃のものだと思われるので、データの側を採りました。

2 倍キャンペーンとブーストの掛け合わせ方だけは確かめられていません。このツールは「2 倍したうえでブーストを掛ける」（×2 ×3.5）として計算しています。足し算（×(1＋1＋2.5)）かもしれません。切っておけば、この不確かさは入りません。

月額商品ぶんの ＋30% / ＋20% も同じ表にあります。PlusExpRatio1: 3000 と PlusExpRatio2: 2000 で、PlusExpProductMonthlyId1/2 に商品 ID が入っています。2 つが重なるかどうかは分からないので、片方だけ選べるようにしてあります。

経験値 2 倍のキャンペーンは、単純に倍で計算しています。消費 AP と経験値が 1 対 1 なので、必要な経験値を倍率で割ったものが必要な AP です。レベルアップの全回復ぶんはそのあとに引いています（もらった AP も同じ倍率で経験値になるため）。

気をつけていること。AP の上限は先生レベルに連動していて、Lv1 では 24、Lv90 で 240 です。「1 日 240 の自然回復」を取り切れるのは、上限に届く前に使っているときで、放っておくと上限で止まります。上の表の「上限まで貯まる時間」がその目安です。

出典 — electricgoat/ba-data（レベル表・AP の内訳）、神ゲー攻略「先生レベル」（レベルアップの AP 回復）、ゲームエイト「熟達証書」（Lv90 到達後の変換と週の上限）。裏取りに ゲームエイト「APの回復方法一覧と1日の自然回復量」と神ゲー攻略「APの効率的な使い方と回復方法」。
