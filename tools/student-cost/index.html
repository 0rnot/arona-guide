数字の出どころ

素材とクレジットは、ゲームのレシピをそのまま読んでいます。レシピの Id は 生徒 Id × 1000 ＋ 枠 × 100 ＋ 段で並んでいて、枠 0 が星上げ、枠 1 が EX スキル、枠 2 がそれ以外のスキル、枠 3 が固有武器、枠 4 が愛用品です。中身は DB/RecipeIngredientExcelTable.json の CostAmount（クレジット）と IngredientId / IngredientAmount（素材）です。

ノーマル・パッシブ・サブの 3 つはどれも枠 2 の同じ表を使います。ゲームの中でも、この 3 つは同じ素材と同じクレジットで上がります。

スキルの ◎ と「キリのいい Lv まで」はデータではなく攻略サイトの記載です。ブルアカ Wiki「スキル」に「EXスキルはLv3とLv5になった際に数値が大きく伸びる」「EX以外のスキルはLv4、Lv7、Lv10になった際に数値が大きく伸びる」「最大まで育成する余裕がない場合は数値が大きく上がるキリのいいLvを目指すと効率がいい」とあります。ゲームエイト「スキル上げのおすすめキャラ」にも「EXはレベル3と5、その他のノーマル・パッシブ・サブスキルはレベル4・7・10に到達した際に、スキルの倍率が大きく上がります」とあり、2 サイトで一致します（2026 年 8 月 31 日に確認）。ボタンはこれに沿って Lv90・EX Lv5・ほかのスキル Lv7 を入れます。 Lv10 まで行かないのは、その 1 段だけで秘伝ノート 1 冊と 400 万クレジットが要るからです。どの生徒でもこれが正解、という話ではありません。手で書き換えてください。

固有武器は★4 までです。Excel/CharacterWeaponExcelTable.json の Unlock は 224 本すべて [true, true, true, false, false] で★3 に見えますが、こちらは止まっている写しです。 DB/CharacterWeaponExcelTable.json は 275 本あって、どれも [true, true, true, true, false] です。日本で開いている段は SchaleDB の config.json の Regions[Jp].WeaponMaxLevel（60 ＝★4）から取っています。★3→★4 の神名文字だけ、レシピの値が「1 個」の仮置きのままです—— クレジットは 2000000 と実数が入っているので、個数だけ ゲームエイトの200 個で補っています（固有武器の強化計算機・星上げの計算機と同じ値）。 2026-08-31 まで★3 で止めていました。

レベルの必要経験値は DB/CharacterLevelExcelTable.json そのままです。 Lv1 から Lv90 までの合計は —。レポートの経験値は初級 50 ／ 中級 500 ／ 上級 2,000 ／ 最上級 10,000 で、これもデータの値です。

レベル上げのクレジットは 1 経験値につき 7 で計算しています。この 7 は Excel/ConstCommonExcelTable.json の CharacterLvUpCoefficient です。ブルアカ Wiki「経験値表」の「育成にはレポートとクレジットが必要で、1EXPあたり7クレジットのコストが掛かる」という記載によります。 Lv1 から Lv90 まででちょうど — になり、同ページの「約875万」と合います。

愛用品を持っている生徒は — 人です。持っていない生徒では、その行を選べません。固有武器も同じで、持っていない生徒では選べません。

絆ランクの贈り物と、装備の設計図はこのツールでは数えていません。絆ランク計算機と装備設計図の周回計算機にあります。

出典 — SchaleDB（生徒・素材の名前とアイコン）、 electricgoat/ba-data（レシピ・経験値表）、SchaleDB config.json（日本で開いている固有武器の段）、ゲームエイト（★3→★4 の神名文字 200 個）。取得は —。
