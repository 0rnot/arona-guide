数字の出どころ

経験値もパーツも、ゲームの表をそのまま読んでいます。

  • レベルごとの経験値は Excel/CharacterWeaponLevelExcelTable.json（70 行）。 TotalExp は「その行のレベルに到達するまで」ではなく「次のレベルまで」の累計です。 行 Level: 49 の TotalExp が 26280 で、これが Lv1 → Lv50 のぶん。 この 26,280 は外の数字とも合っています —— ゲームエイト「経験値テーブル一覧」の 「固有武器1つのレベルを1から最大の50まで育てるには、26,280の経験値が必要」と一致しました。 ここがずれたらデータを作る側で止まります。
  • 武器パーツは ItemExcelTable には 1 件も入っていません。 SchaleDB の equipment の側に Category が WeaponExpGrowthA / B / C / Z として入っています（Id 10〜43 の 16 種）。 1 個ぶんの経験値は LevelUpFeedExp で、4 系統とも 10 / 50 / 200 / 1000 です
  • 1.5 倍になる組み合わせは Excel/CharacterWeaponExpBonusExcelTable.json（武器種 11 種）。 値は 15000（1.5 倍）か 10000（等倍）の 2 つだけでした。 ゲーム内の説明文とも突き合わせています —— SchaleDB の localization の WeaponPartExpBonus に「SMG、SG、HGおよびFTの固有武器の強化時に獲得EXPが1.5倍になる。」などとあり、 表の 15000 の並びと一致します
  • ★ごとのレベル上限は Excel/CharacterWeaponExcelTable.json の MaxLevel。 224 本すべてで 30 / 40 / 50 / 60 / 70 と同じであることを数えて確かめています
  • ★の上限は Unlock の列を見ていません。あちらは 224 本すべて [true, true, true, false, false]（＝★3 まで）ですが、 JP はもう★4 まで開いています。SchaleDB の config.json の Regions で JP の WeaponMaxLevel が 60 ＝ ★4 なので、そちらを採りました。 ba-data の jp ブランチが追いついていないところです
  • ★上げに要る神名文字とクレジットは RecipeId を RecipeExcelTable → RecipeIngredientExcelTable と辿ったもの。 224 本すべてで同じ値でした。★1→2 が 120 個 / 1,000,000、 ★2→3 が 180 個 / 1,500,000 です
  • ★3→★4 の神名文字だけ、ゲームのデータが仮置きのままです。 224 本すべてが IngredientAmount = 1 で、クレジットの 2000000 だけ実数が入っています。 そこで個数は外の出典から 200 個を採りました —— ゲームエイト「固有4のおすすめキャラと必要数」の 「★3→★4の必要素材／神名文字：200個／クレジット：200万／神名のカケラ換算 1000」。 クレジットがゲームのデータと一致しているので、個数だけ補う形にしています。 データ側が 1 でなくなったら、この差し替えを外すよう作る側に見張りを入れてあります
  • ★2 で武器のパッシブスキルが開き、★3 で地形適性が 1 段上がることは同じ表の LearnSkillSlot と StatType / StatValue。 224 本すべて同じ並びで、地形適性の上がり幅だけ 196 本が ＋1、28 本が ＋2 でした

レベル上げのクレジットは出していません。 Excel/ConstCommonExcelTable.json に WeaponLvUpCoefficient という値 （—）はあります。生徒のレベル上げが CharacterLvUpCoefficient ×経験値という形なので同じだろうとは思いますが、 実機で突き合わせていないので画面には出しません。確かめが取れたら足します。

手持ちのパーツを入れる欄は付けていません。16 種類ぶんの入力はスマホで使いものにならず、 「どの順に食わせるか」で結果が変わるためです。代わりに「そのパーツ 1 種類だけで賄うと何個か」を 16 種ぶん並べています。混ぜて使うときは、この表の数を目安に足し合わせてください。

出典 — electricgoat/ba-data（経験値・倍率・★のレシピ）、 SchaleDB（武器パーツ・生徒・絵・JP の★上限）、 ゲームエイト（★3→★4 の神名文字）。取得は —。
