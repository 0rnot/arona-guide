攻撃属性と装甲の倍率

×2.0（Weak） ×1.5（Effective） ×1.0 ×0.5（Resist）
数字の出どころ

倍率の表は、ゲームのデータ 2 か所から取って突き合わせています。片方だけだと足りません。

  • SchaleDB の config.json の TypeEffectiveness。攻撃属性 6 種 × 装甲 7 種が全部入っています
  • ba-data の DB/BulletArmorDamageFactorExcelTable.json（56 行 = 攻撃属性 8 種 × 装甲 7 種）。DamageRate が 10000 分率で、20000 が ×2.0 です
  • 重なる — 升は 1 つずつ照合して、ぜんぶ一致しました。食い違う升が出たらデータを作るときに止まります
  • 「分解（Chemical）」と「複合装甲（CompositeArmor）」の行は DB/ 側に入っています（同じリポジトリの Excel/ 側は 42 行のまま止まっていて、この 14 行がありません）。複合装甲の生徒も 2 人います。
  • 分解と複合装甲の升はブルアカ攻略wiki（Gamerch）「分解と複合装甲の相性」とも一致しました——「分解は複合装甲に 2 倍有利／重装甲に 1.5 倍有利／軽装備に半減／その他は等倍」「複合装甲は分解に 2 倍弱点／神秘・振動に半減／その他は等倍」。データと記事が別々に一致したので、読み違いではありません。

×1.5 という段があります。振動 → 特殊装甲と、分解 → 重装甲の 2 つだけです（DamageAttribute が Effective）。ほかは ×2.0 / ×1.0 / ×0.5 の 3 段です。

地形適性は DB/TerrainAdaptationFactorExcelTable.json（18 行）です。市街地・屋外・屋内の 3 つ × 6 段で、3 つの地形で値は 1 つも変わりません（これも数えて確かめています）。 AttackPowerFactor が 10000 分率で 13000 / 12000 / 11000 / 10000 / 9000 / 8000——SS で ×1.3、D で ×0.8。 これは ゲームエイト「地形適性（戦地適性）の倍率と効果・上げ方」の「SS 1.3倍 / S 1.2倍 / A 1.1倍 / B 1.0倍 / C 0.9倍 / D 0.8倍」と一致します。

ShotFactor と BlockFactor の意味は断定しません。どちらも 7500 / 6000 / 4500 / 3000 / 1500 / 0 と並んでいて、遮蔽まわりの値であることは 同じ攻略wikiの「戦地適性で遮蔽物利用時の成功率が変化します。戦地適性が高ければ遮蔽物に隠れているときの BLOCK 率が上昇したり」という記述から分かりますが、数値の単位までは書いた出どころが見つかりませんでした。表には生の数字だけ載せています。同じ表の AccuracyFactor と DodgeFactor は 18 行すべて 0 なので出していません。

生徒の攻撃属性・装甲・地形適性は SchaleDB の students から。地形適性は StreetBattleAdaptation / OutdoorBattleAdaptation / IndoorBattleAdaptation に 0〜5 の数字で入っていて、0 が D、5 が SS です。— 人ぶん、範囲の外に出ていないことを確かめています。 固有武器の 3 凸で適性が 1 段上がる子がいますが、ここでは素の値を出しています。

出典 — SchaleDB（倍率表・生徒）、electricgoat/ba-data（倍率表・地形適性）、ゲームエイトとGamerch（地形と分解・複合装甲の裏取り）。取得は —。
