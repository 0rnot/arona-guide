数字の出どころ

開催の日付・ボス・地形は、ゲームのデータそのままです。 raids.min.json の RaidSeasons にある Seasons（総力戦）と EliminateSeasons（大決戦）を、 Start / End（どちらも UNIX 秒）で並べています。時刻はすべて日本時間で出しています。見ている端末の時計に合わせると、海外から見たときに日付がずれるためです。

RaidSeasons はサーバーごとに 3 本入っていて、先頭が日本です。先頭の最後のシーズンが日本の開催日と合うことを確かめて使っています。

大決戦の「Torment に挑戦できる防御タイプ」は OpenDifficulty です。防御タイプごとに、その回で開く難易度の番号が入っています。番号は Normal・Hard・VeryHard・Hardcore・Extreme・Insane・Torment・Lunatic の順で、 6 なら Torment まで、5 なら Insane までです。

「次の目安」は、直近 6 回の間隔から最短と中央値の 2 つを取って、最後の開始日にそれぞれ足した幅です。ゲームのデータに次回の予定は入っていません。実際の告知は公式 X の「総力戦＆大決戦スケジュール」と「予告」で出ます。

ボスの装甲と攻撃属性は Raid の ArmorType / BulletType / BulletTypeInsane です。 Insane 以上では攻撃属性が変わるボスがいるので、両方を出しています。相性の詳細は総力戦の相性チェッカーにあります。
