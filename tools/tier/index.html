数字と画像の出どころ

生徒の一覧・学校・役割・攻撃属性・防御属性・区分・レア度、それに顔のアイコンは SchaleDB の data/jp/students.min.json と images/student/collection/ から取っています（icon は 120×120 で、 Tier 表のように大きく出すと粗いので、200×226 の collection を正方形に切って使っています）。日本語の呼び名も同じところの data/jp/localization.min.json です。

data.js は scripts/build-tool-data.py が作っています。 GitHub Actions が毎日回しているので、生徒が増えれば自動でここにも並びます。いま — 人です。取得は —。

順位そのものはこのツールでは決めません。誰が強いかは編成と相手で変わるもので、ここが用意しているのは並べる場所だけです。
