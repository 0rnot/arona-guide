数字の出どころ

レポートの経験値と、生徒の必要経験値は、ゲームのデータそのままです。推測はありません。

  • Excel/ItemExcelTable.json（SchaleDB の items）— 初級レポート ExpValue: 50／中級 500／上級 2000／最上級 10000
  • data/jp/equipment.min.json の Category: "Exp" — 強化珠の LevelUpFeedExp が 90 / 360 / 1440 / 5760
  • Excel/CharacterLevelExcelTable.json — Lv90 の TotalExp: 1249185
  • Excel/EquipmentLevelExcelTable.json — Lv70 の TotalExp が Tier1 から順に 381 / 1841 / 5456 / 12326 / 17326 / 23551 / 31141 / 40231 / 50961 / 63466。 足すとちょうど 246,680 で、これが装備 1 個を Tier1 Lv1 から Tier10 Lv70 まで上げるのに要る経験値です

強化珠の経験値もゲームのデータそのままです。 レポートが items に入っているのに対して、強化珠は equipment のほうに Category: "Exp" として入っていて、LevelUpFeedExp が 初級 90／中級 360／上級 1440／最上級 5760 です。 246,680 ÷ 5,760 = 42.8 で「最上級強化珠 43 個ぶん」、 1,249,185 ÷ 10,000 = 124.9 で「最上級レポート 125 個ぶん」—— どちらも攻略サイトに載っている数字と同じでした。

1 人を仕上げるクレジット（55,000,000）は目安です。 ゲームのデータからは出せませんでした。レベル上げ・スキル 4 種・装備 3 個をぜんぶ最大にした場合のおおよその額で、 星上げ（神名文字）は入っていません。自分の育て方に合わせて書き換えてください。

出典 — electricgoat/ba-data（jp ブランチ）、 SchaleDB、 ゲームエイト「生徒レベルの上げ方」（Lv90 の累計経験値 1,249,185）。
