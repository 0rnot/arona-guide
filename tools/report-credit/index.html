どれもゲームのデータそのままです。生徒の育成計算機の「総額」と同じデータ・同じ数え方です。

  • DB/ItemExcelTable.json の StackableFunction（SchaleDB の items では ExpValue）— レポート 1 枚の経験値 50 / 500 / 2000 / 10000
  • DB/CharacterLevelExcelTable.json — Lv1→Lv90 の経験値 —。1 経験値 — クレジット（ConstCommonExcelTable の CharacterLvUpCoefficient）
  • DB/RecipeIngredientExcelTable.json の CostAmount — スキルのクレジット
  • SchaleDB equipment の RecipeCost と DB/EquipmentLevelExcelTable.json の TotalExp（× 4）— 装備の Tier 上げと強化
