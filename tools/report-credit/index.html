数字の出どころ

レポートの経験値と、生徒の必要経験値は、ゲームのデータそのままです。推測はありません。

  • DB/ItemExcelTable.json の StackableFunction（SchaleDB の items では ExpValue。値は同じ）— 初級レポート 50／中級 500／上級 2000／最上級 10000
  • data/jp/equipment.min.json の Category: "Exp" — 強化珠の LevelUpFeedExp が 90 / 360 / 1440 / 5760
  • DB/CharacterLevelExcelTable.json — Lv90 の TotalExp: 1249185
  • DB/EquipmentLevelExcelTable.json — Lv70 の TotalExp が Tier1 から順に 381 / 1841 / 5456 / 12326 / 17326 / 23551 / 31141 / 40231 / 50961 / 63466。足すとちょうど 246,680 で、これが装備 1 個を Tier1 Lv1 から Tier10 Lv70 まで上げるのに要る経験値です

強化珠の経験値もゲームのデータそのままです。レポートが items に入っているのに対して、強化珠は equipment のほうに Category: "Exp" として入っていて、LevelUpFeedExp が初級 90／中級 360／上級 1440／最上級 5760 です。 246,680 ÷ 5,760 = 42.8 で「最上級強化珠 43 個ぶん」、 1,249,185 ÷ 10,000 = 124.9 で「最上級レポート 125 個ぶん」。どちらも攻略サイトに載っている数字と同じでした。

1 人を仕上げるクレジット（51,721,955）は、次の 4 つを足したものです。レベル Lv1→Lv90 が 8,744,295（1,249,185 経験値 × 7）、 EX スキル Lv1→Lv5 が 13,580,000、ノーマル・パッシブ・サブの 3 つを Lv1→Lv10 で 26,437,500、装備 3 部位を T1→T10 で 2,960,160 （1 部位ぶんの 246,680 経験値 × 4 × 3 部位）。星上げ（神名文字）・固有武器・愛用品は入っていません。 生徒ごとの額は生徒 1 人の育成費用で出せます——ただしあちらは装備を含みませんので、装備ぶんは装備の強化珠計算機で別に足してください。 自分の育て方に合わせて書き換えてください。

出典 — electricgoat/ba-data（jp ブランチ）、 SchaleDB、ゲームエイト「生徒レベルの上げ方」（Lv90 の累計経験値 1,249,185）。
