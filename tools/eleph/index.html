数字の出どころ

要る神名文字とクレジットは、ゲームのレシピをそのまま読んでいます。推測はありません。

  • Excel/CharacterTranscendenceExcelTable.json — 生徒ごとに RecipeId が 4 つ（★1→2、2→3、3→4、4→5）並んでいます
  • その Id を Excel/RecipeExcelTable.json → Excel/RecipeIngredientExcelTable.json と辿ると、 CostAmount（クレジット）と IngredientId（その子の神名文字）と IngredientAmount（個数）が出ます
  • — 人ぶんを 1 人ずつ数えて、4 段とも全員同じ値であることを確かめています。 神名文字は 30 / 80 / 100 / 120 で合計 330 個、クレジットは 10,000 / 40,000 / 200,000 / 1,000,000 で合計 1,250,000 です。 1 人でも違う値が出たら、データを作る側で止まるようにしてあります。
  • 星で上がるステータスは同じ表の StatBonusRateAttack / StatBonusRateHP / StatBonusRateHeal。 10000 分率で、★2 から順に攻撃力 1000 / 1200 / 1400 / 1700、最大 HP 500 / 700 / 900 / 1400、 回復力 750 / 1000 / 1200 / 1500 です。段ごとの足し算なので、★5 では攻撃力が ＋53%、最大 HP が ＋35%、回復力が ＋44.5% になります
  • 「足し算」だという根拠は SchaleDB 本体の計算そのものです。あちらの JavaScript が生徒のステータスを出すとき、 1 + (StatBonusRate.slice(0, StarGrade).reduce((a, b) => a + b, 0)) / 1e4 を基礎値に掛けています。 slice(0, 星) で ★1 から今の星までを切り出して reduce で足しているので、★5 なら 0 + 1000 + 1200 + 1400 + 1700 = 5300、係数は 1.53 です。 既定値として書かれている配列も [0, 1e3, 1200, 1400, 1700] / [0, 500, 700, 900, 1400] / [0, 750, 1e3, 1200, 1500] で、上のゲームデータと一致します （schaledb.com の assets/index-*.js。2026-08-30 に読みました）
  • 絆ランクの上限は同じ表の MaxFavorLevel。10 / 10 / 20 / 20 / 100 で、★3 で 20、★5 で 100 まで開きます

★5 のあとは「限界解放」です。★の上げ方を神秘解放、固有武器の上げ方を限界解放と呼び分けます （ブルアカ攻略 Wiki の「神秘解放/限界解放」）。 ★5 になると固有武器が使えるようになり、その状態が固有1です。そこから固有2・固有3・固有4 と続きます。

  • Excel/CharacterWeaponExcelTable.json の RecipeId が段の並びです。 ★のときと同じように RecipeExcelTable → RecipeIngredientExcelTable と辿ります。 神名文字は 120 / 180 / 200、クレジットは 1,000,000 / 1,500,000 / 2,000,000 です
  • 固有武器のレベル上限は同じ表の MaxLevel。30 / 40 / 50 / 60 / 70 で、 固有1 で Lv30、固有4 で Lv60 です（70 の段＝固有5 は日本ではまだ出ていません）
  • 覚えるものも同じ表から読んでいます。LearnSkillSlot の 2 番目が Passive01 なので 固有2 でパッシブスキル＋、StatType の 3 番目が 〇〇BattleAdaptation_Base なので 固有3 で地形適性です。上がり幅は生徒ごとに違います—— ＋1 段が 196 人、＋2 段が 28 人で、StatValue をその子ぶん読んでいます

ここだけはゲームのデータから取れていません。固有3→固有4 の神名文字です。 RecipeIngredientExcelTable の該当行は IngredientAmount が 1 の仮置きで、 クレジットの 2,000,000 のほうは入っています。 ba-data の jp ブランチが 2025-05-21（v1.57.342698）で止まっているのが理由で、 Unlock も 224 人全員が [true, true, true, false, false] ＝ 固有3 までのままです。 日本ではもう固有4 まで出ていることは、SchaleDB の config.json の Regions の Jp が "WeaponMaxLevel": 60（＝ MaxLevel の 4 番目）になっていることで確かめました。

そこで 神名文字 200 個だけは game8 の「固有武器★4の解放必要素材」から取っています（2026-08-30 に取得）。 裏取りは 2 本立てです。ひとつは、同じ記事の累計「★1→固有★4 は 830」が、 ★1→★5 の 330（＝ 30+80+100+120。ブルアカ攻略 Wiki と ba-data が一致）に 120+180+200 を足した値とぴたり合うこと。 もうひとつは、同記事の「★3→固有★4 は 720」が、このツールで ★3 の生徒を固有4 まで上げたときの 720 個と一致することです。

固有4 で増えるものは、ゲームのデータには入っていません。 StatType の 4 番目は None のままです。 ストライカーは自分の攻撃属性の特効が ＋10%、スペシャルはコスト上限が ＋0.5で、 これは上の game8 と、ブルアカ攻略 Wiki の「限界解放 星3→星4」の欄 （ST:〇〇特効加算+10%、SP:最大コスト0.5増加）が一致しています。 どちらを出すかは、その子の SquadType（Main がストライカー、 Support がスペシャル）で切り替えています。

データに星上げのレシピが入っていない生徒は、この一覧に出しません。 IngredientId が「神名のカケラ」（Id 23）を 999 個という仮置きの行になっている生徒と、 レシピそのものが空の生徒がいます。実装が追いついていないだけなので、ゲーム側では上げられます。 このツールは読めた — 人ぶんだけを出しています。

神名文字の入手先は数字を持っていません。募集での重複、総力戦や大決戦でもらえる「神名のカケラ」との交換、 ショップなど、経路が複数あって手持ちの状況で変わるためです。1 週間ぶんの見込みは自分で入れる形にしてあります。

出典 — electricgoat/ba-data（レシピと上がり幅）、 SchaleDB（生徒と道具の名前、顔の絵、日本の上限）、 ブルアカ攻略 Wiki（呼び名と各段の恩恵）、 game8（固有3→4 の神名文字）。取得は —。
